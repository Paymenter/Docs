## Developer notices:

Changes in this release may affect your existing integrations. The following important changes have been made:

- The Filament package has been updated to version 4.0, if your extension uses admin resources or pages please review the [Filament upgrade guide](https://filamentphp.com/docs/4.x/upgrade-guide) for any necessary changes.
- `canUseGateway` on gateways now passes the `$total`, `$currency`, `$type`, and `$items` parameters. This has changed from: `$items`, `$type`
