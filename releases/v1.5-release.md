# v1.5 Release

## What's new?

* **Session and login hardening** - added support for multiple remember-me sessions, session locking middleware, and an auth login hook.
* **Service and support UI improvements** - added service labeling and ticket message avatars.
* **New API surface** - added products and categories view endpoints.
* **Mail settings test action** - added a send test email action to verify mail configuration from the panel.
* **Livewire v4 and Filament v5** - upgraded the stack to the latest major versions.

And many many more small tweaks and improvements. Read the full changelog [here](https://github.com/Paymenter/Paymenter/compare/v1.4.7...v1.5.0).

## Security improvements

This release resolves the following CVEs:

- CVE-2026-44583 (score 5.3)
- CVE-2026-44584 (score 4.3)
- CVE-2026-44585 (score 5.4)

More details on these vulnerabilities will be shared in the coming weeks after users have had sufficient time to update. In the meantime, we highly recommend updating to this release as soon as possible to benefit from these security improvements.
