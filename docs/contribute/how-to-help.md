# Help Building Paymenter

Paymenter is a open-source project and is worked on by multiple contributors. If you want to help us, please follow the steps below.

## How to help building paymenter

1. Create an account on [Github](https://github.com) if you don't have one already .
2. Go to the Github repository: [Paymenter on Github](https://github.com/Paymenter/Paymenter)
3. Fork the repository
4. Start modifying!
5. Once you are done, make a pull request.
6. Wait for the review to be completed. If your pull request gets approved, your modifications will be added to the next release/BETA.
