# Servers

Servers in Paymenter are used to provision and manage services for your customers. They can be game servers, web hosting servers, or any other type of server that you want to integrate with Paymenter.

## Adding a Server

To add a server, navigate to **Admin ➜ Products ➜ Servers** and click on the "Add Server" button. You will be presented with a form where you can fill in the details of your server.

| Field            | Description                                                                                         |
|------------------|-----------------------------------------------------------------------------------------------------|
| Name             | The name of the server. This is what you will see in the admin panel.                              |
| Extension       | The server extension to use. This determines how the server will be managed and what features are available. |

Once you have selected an extension, additional fields may appear that are specific to the selected extension.

## Available Servers

Paymenter includes several built-in server extensions, and you can also install additional extensions from the [Paymenter Marketplace](https://paymenter.org/marketplace).

- [Convoy](../../extensions/convoy)
- [DirectAdmin](../../extensions/directadmin)
- [Enhance](../../extensions/enhance)
- [Plesk](../../extensions/plesk)
- [Proxmox](../../extensions/proxmox) (only available as Paid Extension)
- [Pterodactyl](../../extensions/pterodactyl)
- [VirtFusion](../../extensions/virtfusion)
- [Virtualizor](../../extensions/virtualizor)
