# Gateways

Gateways in Paymenter are used to process payments and subscriptions using various payment providers. They handle the communication between your Paymenter instance and the payment provider, allowing you to accept payments from your customers.

## Adding a Gateway

To add a gateway, navigate to **Admin ➜ Payments ➜ Gateways** and click on the "Add Gateway" button. You will be presented with a form where you can fill in the details of your gateway.

| Field            | Description                                                                                         |
|------------------|-----------------------------------------------------------------------------------------------------|
| Name             | The name of the gateway. This is what you will see in the admin panel.                              |
| Extension       | The gateway extension to use. This determines how the gateway will process payments and what features are available. |

Once you have selected an extension, additional fields may appear that are specific to the selected extension.

## Available Gateways

Paymenter includes several built-in gateway extensions, and you can also install additional extensions from the [Paymenter Marketplace](https://paymenter.org/marketplace).
